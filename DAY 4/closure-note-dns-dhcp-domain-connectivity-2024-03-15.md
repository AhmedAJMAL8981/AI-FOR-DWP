# Closure Note — INC-2024-03-15-FINFLOOR3

Resolved. Cause: DHCP scope for the Floor 3 subnet was not updated after the overnight DNS migration and continued to hand out the decommissioned DNS server addresses (10.10.3.250 / 172.16.5.5) instead of the new server (10.10.0.10), preventing affected machines (FB031, FB055–FB057) from resolving the domain controller and completing login. Action: DHCP scope option 6 for the Floor 3 subnet updated to hand out DNS server 10.10.0.10; DHCP lease renewed and DNS cache flushed on affected machines; Netlogon secure channel reset via `nltest /sc_reset:finbridge.local`; Group Policy refresh confirmed via `gpupdate /force` and GroupPolicy Event 1500. Preventive: DNS migration and decommission runbook to be updated to include a mandatory DHCP scope option 6 validation step on all affected subnets before any DNS server is decommissioned; post-migration DHCP audit to be implemented to alert on any scope still referencing a decommissioned DNS IP. User confirmed working.
