# New laptop stopped before you could start using it

If your new laptop stops before you can start using it, your files are safe. This happens before any of your files are added, so nothing has been lost.

What you can do:
1. Wait 15 minutes and see if it starts again.
2. If it is still stuck, sign out once or restart the laptop once.
3. Try again.
4. If it still will not move on, contact the service desk.

Contact the service desk if the laptop still will not finish after you have waited and tried again.

When you report it, include these details:
- The laptop name: DESKTOP-FB099
- The date and time the problem started
- What you saw on screen
- That it stopped before you could start working
- That your files were safe and nothing was lost
