# Floor 6 Partner Update
**14 August 2026**

## What happened
This morning we found three separate issues affecting Floor 6 Legal. Some people could not sign in or were taking a long time to get into their work account. Some people also lost desktop shortcuts after logging in. In a separate security review, one user reported seeing client matter content in Copilot that they should not have been able to see.

We are treating these as separate issues so each one can be handled correctly.

## What we are doing
We are actively working on all three items now. For the sign-in issue, we are checking recent system changes and affected devices to find the cause and restore normal access safely. For the missing shortcut issue, we are checking whether this is linked to recent device changes or a desktop setup problem and restoring shortcuts where needed.

For the Copilot matter, we have started a security review, preserved evidence, and temporarily limited access while we check permissions and confirm whether any other information was exposed. Security, Compliance, and Legal are involved in that review.

## What is still open
We do not yet have one final cause for the sign-in issue or the missing shortcut issue. We are still checking whether recent changes on Floor 6 are linked to either problem.

The Copilot review is still open. We have one confirmed report, but we do not yet know whether any other users were affected or whether any client information was viewed beyond that report. We will share the next update as soon as the evidence is clear.

## Bottom line
We know this has disrupted work on Floor 6, and we are handling each issue separately so we can fix them safely and completely. The security matter is being treated with priority, and we will continue to provide updates as soon as facts are confirmed.
